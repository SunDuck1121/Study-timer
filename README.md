# 뽀모도로 공부 타이머

브라우저에서 바로 쓰는 집중 타이머입니다. 설치 없이 이 저장소의 GitHub Pages 주소만 열면 됩니다.

## 기능

- **뽀모도로 공부 타이머**: 25분, 50분, 90분 프리셋 또는 직접 입력한 집중 시간과 휴식 시간으로 세션을 진행합니다.
- **기록**: 오늘 집중 시간, 완료 세션 수, 연속 기록, 최근 7일 차트와 오늘의 세션 목록을 보여 줍니다. 설정에서 JSON·CSV로 내보낼 수 있습니다.
- **화면 이탈 감지**: 집중 중 다른 화면으로 나가면 이탈 횟수와 이탈 시간을 세고, 세션이 끝나면 요약에 표시합니다.
- **홈 화면 추가**: iPhone Safari에서 공유 버튼 → **홈 화면에 추가**를 누르면 앱처럼 실행할 수 있습니다.

## 바로 시작

주소 뒤에 `#start=50`을 붙이면 50분 세션이 바로 시작됩니다.

예: `https://sunduck1121.github.io/Study-timer/#start=50`

`#start`만 붙이면 현재 설정된 시간으로 시작합니다. `#start=25`처럼 분 단위 숫자를 바꾸면 그 시간으로 시작합니다.
